# 凑数计算器

一个基于 Flask 的组合搜索工具，用于从多个人员的金额列表中找出能凑出目标金额的组合方案。

![计算示例](计算示例.png)

## 功能

- **普通计算** — 指定目标金额和发起人，搜索所有精确匹配或最接近的组合方案
- **系统解算** — 在「每人最多发起一次、参与一次」的约束下，找出一组最优解，最大化凑出的总单数
- 支持多个目标金额同时计算
- 人员/发起人可灵活勾选，数字列表可折叠查看

## 快速开始

### 安装依赖

```bash
pip install flask openpyxl pandas
```

### 准备数据

将 Excel 数据文件命名为 `data.xlsx`，放在项目根目录下。

**数据格式要求：**

- 每一列的**列头**为人员姓名
- 列头下方的单元格为金额数字（整数），每人一列
- 空单元格会被自动忽略

示例：

| 张三 | 李四 | 王五 |
|------|------|------|
| 100  | 200  | 50   |
| 300  | 400  |      |
| 500  |      | 150  |

### 运行

```bash
python app.py
```

访问 http://localhost:5000 即可使用。

## 项目结构

```
├── app.py              # Flask 后端，组合搜索算法
├── data.xlsx           # 人员金额数据（Excel 格式）
└── templates/
    └── index.html      # 前端页面
```

## 算法说明

后端使用 DFS + 剪枝策略搜索组合：

- 每个人员的名下金额从大到小排序并去重
- 上限/下限剪枝：利用后缀最大值之和与最小值之和快速排除不可能的分支
- 系统解算模式通过回溯搜索在人员互斥约束下找到最大匹配数
